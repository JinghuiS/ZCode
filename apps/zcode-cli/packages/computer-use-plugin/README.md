# computer-use（官方插件）

ZCode「电脑控制」官方插件，基于 Kimi Computer Use（macOS）的 `kimi-cu mcp` stdio server。

- `.mcp.json`：注册 `kimi-cu` MCP server，经 `scripts/kimi-cu-mcp.sh` 定位本机 KimiCU.app。
- `scripts/install-kimi-cu.sh`：调用官方安装脚本。
- `skills/computer-use/SKILL.md`：给模型的工作流与安全约束。

设计见仓库 `specs/computer-use-kimi.md`。
